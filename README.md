# הרמי / Hermy — AI ישראלי שעושה סדר בכסף ובחיים בישראל

זה קוד המקור של [האתר של הרמי](https://yonatan2021.github.io/hermy-blog/) — נכס דיגיטלי קטן שעוזר לישראלים לעשות סדר בכסף, זכויות, בירוקרטיה וכלכלה ביתית דרך מדריכים וכלים פשוטים.

המרכז החדש הוא **הרמי עושה סדר בכסף**: תלוש, פנסיה, זכויות, ביטוחים, הלוואות, עמלות, קניות ושאלות בדיקה שאפשר להתחיל מהן בלי למסור מידע אישי.

## מה יש כאן

- **סדר בכסף** — דף הכניסה הראשי לבדיקות כסף ביתיות.
- **מדריכים ותובנות** — הסברים, צ׳ק־ליסטים ותובנות שימושיות על כסף, עסקים, זכויות ובירוקרטיה.
- **כלים** — מחשבונים, צ׳ק־ליסטים ותבניות החלטה פשוטות, בלי איסוף מידע אישי.

## Tech Stack

- **Jekyll** — static site generator
- **GitHub Pages** — hosting
- **GitHub Actions** — deploy ואוטומציות פרסום
- **RTL-first Hebrew UI** — עברית קודם, אנגלית כשצריך
- **Custom dark theme** — עיצוב שקט, טכני וחם

## מבנה הפרויקט

```text
├── _config.yml          # הגדרות האתר
├── _data/               # נתונים ציבוריים לחדר היום
├── _includes/           # רכיבי Liquid קטנים
├── _layouts/            # תבניות HTML
├── _posts/              # פוסטים
├── assets/css/          # SCSS ראשי
├── tools/               # כלים אינטראקטיביים / עמודי כלי
├── DESIGN.md            # עקרונות עיצוב
└── .github/workflows/   # deploy ואוטומציות
```

## הרצה מקומית

```bash
bundle install
bundle exec jekyll serve
```

אם ה־Bundler המקומי לא תואם ל־`Gemfile.lock`, סביבת GitHub Actions עדיין בונה עם Ruby 3.2 ו־`ruby/setup-ruby`. במכונה מקומית יש ליישר את גרסת Bundler או לעדכן את ה־lock בהתאם לסביבת הפיתוח.
