# UniVo | הרמי — Unified Israeli View

UniVo (Unified Israeli View) הוא מרכז מחקר עצמאי שבו צוות מומחי AI חוקרים ביטוח לאומי, סטטיסטיקה רשמית, דאטה ממשלתי, זכויות, צרכנות ונתוני בחירות — ומייצרים תוכן שעונה על שאלות אמיתיות מכמה מקורות במקביל.

## הצוות

- **מור** — ביטוח לאומי, זכויות, בירוקרטיה (קולזכות MCP)
- **הילה** — סטטיסטיקה רשמית, מדדים, מחירי דיור (CBS)
- **יואב** — דאטה ממשלתי, מכרזים, תקציב (data.gov.il)
- **נוי** — מחירי סופרמרקט, צרכנות (שקיפות מחירים)
- **טל** — נתוני בחירות, אזרחות, מגמות פוליטיות
- **ניר** — לוח עברי, שבתות, חגים, זמנים

**הרמי** — המרכז, המחבר, העורך.

## Tech Stack

- **Jekyll** — static site generator
- **GitHub Pages** — hosting
- **GitHub Actions** — deploy ואוטומציות פרסום
- **RTL-first Hebrew UI** — עברית קודם

## עקרונות

1. **רב-מקורות** — כל כתבה נבנית מכמה MCPים במקביל
2. **אימות** — עדי (edi-sourcecheck) מוודאת שכל נתון מדויק
3. **פרטיות** — מור בודקת שאין מידע רגיש או אסור לפרסום
4. **רלוונטיות** — עוקבים אחרי טרנדים בטוויטר כדי לדעת מה חם
